PricePoint.

What is a used laptop worth? A machine learning project that connects hardware specifications and condition to resale value in Bangladesh’s secondhand market.

01 / CONTEXTThe question behind the model.

Secondhand laptop prices depend on a combination of specifications and physical condition. A brand name or a processor alone cannot describe the whole machine. PricePoint brings those details together to estimate resale value.

The project uses a custom dataset collected from local marketplace listings in Bangladesh. That gives the work a specific context: the prices and machines people encounter in this market. The prediction target is resale price, with brand, processor, RAM, storage, GPU, screen size, age, and condition as inputs.

02 / IMPLEMENTATIONOne problem. Four approaches.

Represent the machine

Python, pandas, and NumPy support working with the laptop records. The feature set spans hardware and usage: specifications describe capability, while age and condition add information about the particular device being sold.

Compare different kinds of regression

The project compares Linear Regression, Decision Tree, Random Forest, and Support Vector Regression using scikit-learn. Each offers a different way to map a laptop’s attributes to a continuous price estimate.

Make evaluation part of the work

MAE, RMSE, and R² provide complementary views of prediction quality. MAE describes average absolute error, RMSE gives greater weight to larger errors, and R² measures how much price variation the model accounts for. Matplotlib supports the analysis and visualization.

03 / TAKEAWAYWhat the project demonstrates.

PricePoint connects a familiar local problem with a complete regression workflow: collecting a relevant dataset, selecting features, comparing several algorithms, and evaluating their predictions.

A useful estimate depends on the data behind it. Marketplace listing prices describe what sellers ask; they do not necessarily record the final transaction. The model’s context therefore matters when interpreting an estimated value.
